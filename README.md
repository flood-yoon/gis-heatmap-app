# 🇰🇷 Korean

## 📌 개요
서울 주요 관광지의 매출 데이터를 기반으로 공간적 분포를 시각화하기 위해 히트맵을 생성하는 GIS 응용 프로그램입니다.  
지도 위에 데이터를 표현하여 매출 밀집도를 직관적으로 파악할 수 있도록 하는 것을 목표로 합니다.

---

## 🚀 주요 기능
- 지도 기반 시각화
- 관광지 위치 마커 표시
- 매출 데이터 기반 히트맵 생성

# 🇺🇸 English

## 📌 Overview
This application generates a heatmap to visualize the spatial distribution of sales data from major tourist locations in Seoul.  
It aims to provide an intuitive understanding of data density by displaying it on a map.

---

## 🚀 Features
- Map-based visualization  
- Marker display for tourist locations  
- Heatmap generation based on sales data  

---

## ▶️ How to Run
1. Run the application  
2. Load the `data/sample.csv` file  

---

## 🛠 Tech Stack
- C#  
- Windows Forms  
- GMap.NET  

---

## 📂 Data
- `sample.csv`: Sales data of tourist locations in Seoul  
- Used to generate heatmap based on location and sales values
